# Privacy

Luma Store can be browsed without an account. Public app listings, app details and downloads do not require sign-in.

## Account data

Luma Store supports direct email/password accounts through Supabase Auth. When you create an account, the authentication service stores the account identifier, email address and authentication data required to operate the account. Passwords are handled by Supabase Auth and are not stored by the Luma Store application itself.

Optional external sign-in providers may also be offered. If you choose one, that provider processes the authentication under its own privacy policy. A Google, GitHub or GitLab account is not required to create a direct Luma Store account.

Signed-in features can store data you intentionally create, including favorites, ratings and review text. Developer features can additionally store developer profile information, submissions, app metadata, funding settings, release information and developer analytics associations.

## Download statistics

Luma Store records aggregate download statistics used for store metrics and developer analytics. These statistics are not sold to advertisers or data brokers.

## Storage and infrastructure

Luma Store uses Supabase for authentication, database and storage functionality and other infrastructure providers where required to operate the service. Those providers may process technical request data such as IP addresses as part of providing their services.

Developer profile images uploaded through the Android app are stored in Luma Store's Supabase Storage project and are publicly readable when used as a public developer avatar.

## Your choices

- Browse and download public apps without signing in.
- Use a direct Luma Store email/password account instead of a social login.
- Use optional external providers only if you choose to.
- Remove favorites and reviews from the app.
- Sign out at any time.
- Open an issue if you have a privacy question or need help with account data.

The website also publishes the current privacy statement at https://luma.free-time.me/privacy.
